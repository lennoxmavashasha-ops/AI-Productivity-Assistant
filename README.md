 AI Workplace Productivity Assistant

## Project Overview

The AI Workplace Productivity Assistant is a web application designed to improve workplace efficiency by automating repetitive tasks using Artificial Intelligence. The application helps users generate professional emails, summarize meeting notes, plan tasks, conduct research, and interact with an AI-powered assistant. The goal is to increase productivity, save time, and support better decision-making in the workplace.

---

## Features

### Smart Email Generator

* Generates professional emails based on user input.
* Supports different tones such as formal, friendly, and persuasive.
* Adapts content for different audiences.

### Meeting Notes Summarizer

* Converts lengthy notes into concise summaries.
* Extracts key points, decisions, and action items.
* Highlights deadlines and responsibilities.

### AI Task Planner

* Creates daily and weekly task schedules.
* Prioritizes tasks based on urgency and importance.
* Suggests productivity improvements.

### AI Research Assistant

* Summarizes articles, reports, and workplace topics.
* Provides key insights and recommendations.
* Simplifies complex information.

### AI Chatbot Assistant

* Interactive AI-powered workplace assistant.
* Answers questions and supports productivity tasks.
* Provides quick access to information and guidance.

## Setup Instructions

### Prerequisites

* Node.js installed
* Internet connection
* Modern web browser

### Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/ai-workplace-productivity-assistant.git
```

2. Navigate to the project folder:

```bash
cd ai-workplace-productivity-assistant
```

3. Install dependencies:

```bash
npm install
```

4. Start the application:

```bash
npm run dev
```

5. Open the application in your browser:

```text
http://localhost:3000
```
